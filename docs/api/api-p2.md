# API一覧（ポンプ）

|ID|リクエスト|引数|返り値|詳細|備考|
|---|---|---|---|---|---|
|API-P2-1|GET|問題ID|ゲーム履歴|ユーザの最新ゲームがあれば、そのユーザ入力の履歴を全て返す。なければ空の履歴を返す。|ユーザIDはセッションから取得|
|API-P2-2|POST|問題ID, ユーザ入力|ゲーム結果|新規ゲームを作成し、その履歴にユーザ入力を追加する。<br>入力を元にゲーム結果(correct, incorrect)を求めて返す。|ユーザIDはセッションから取得<br>毎度API0-1を呼んで新規ゲームとして記録する|

## 備考

- ポンプは`ongoing`なゲームを持たない
- 入力途中の履歴はDBではなくlocalStorageで保持する
