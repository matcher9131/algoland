# API一覧（問題共通）

|ID|リクエスト|引数|返り値|詳細|備考|
|---|---|---|---|---|---|
|API-C-1|POST|問題ID|ゲームID|新規ゲームを作成して返す。|ユーザIDはセッションから取得|
|API-C-2|POST|ゲームID, 結果|なし|該当ゲームを指定した結果にする。<br>結果はcorrect, incorrectのみを認める。|ユーザIDをセッションから取得し、ユーザのゲームでない場合は弾く|
|API-C-3|GET|問題ID|問題に正解した時刻<br>なければ`NULL`|ユーザがその問題に初めて正解した時刻(JST)を返す。|ユーザIDはセッションから取得|
