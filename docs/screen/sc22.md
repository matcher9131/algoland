# sc22 - ポンプLv2

## 問題概要
$H \times W$ マスのグリッドにポンプまたは水場を配置し、得られる水の量を最大化する

ユーザに実際にポンプまたは水場を配置してもらい、得られる水の量が最大値と等しければ正解、そうでなければ不正解とする

## 問題文
M君はとあるシミュレーションゲームをプレイしています。

そのゲームには上水道の概念があり、ポンプと水場を組み合わせることで上水道を供給できます。

M君は縦 $H$ マス×横 $W$ マスのグリッドからなる長方形状の土地を用意し、それぞれのマスにポンプか水場を置くことで、最大効率のポンプ場を作りたいと考えています。

それぞれのポンプが汲み上げる水の量は以下のルールにより決まります

- 周りのポンプや水場の配置によらず、基本 $X$ ガロン
- ポンプに隣接する（斜めを含む）8マスに水場があれば、追加で1マスあたり $Y$ ガロン
  - この追加分は1つの水場の周りにポンプが何個あろうとも、それぞれのポンプに対して発生する

汲み上げられる水の総量が最大になるようなポンプと水場の配置を求めてください。

## 制約
- $H=2, W=3$
- $X=14400, Y=7200$
