# API一覧（呑兵衛）

|ID|リクエスト|引数|返り値|詳細|呼び出すAPI|備考|
|---|---|---|---|---|---|---|
|API-P1-C|POST|問題ID|初期状態のゲーム状態|ゲームを作成し、Lv2なら正解値の設定も行う|API-A-4, API-C-C|-|

|API-P1-U|POST|問題ID, ユーザ入力|ゲーム状態|ユーザの最新ゲームがあれば、それにユーザ入力を追加し、最新ゲーム状態を計算して返す。なければ例外を投げる。|API-A-4|-|
