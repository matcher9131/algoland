# API一覧（ダンジョン）

|ID|リクエスト|引数|返り値|詳細|呼び出すAPI|備考|
|---|---|---|---|---|---|---|
|API-P3-C|POST|問題ID|初期状態のゲーム状態|ゲームを作成し、パターン番号の設定を行う|API-A-4, API-C-C|-|
|API-P3-R|GET|問題ID|ゲーム状態|ユーザの最新ゲームがあれば、そのユーザ入力の履歴を全て返す。なければ空の履歴を返す。|API-A-4|-|
|API-P3-U|POST|ゲーム状態|ゲーム結果|ユーザの最新ゲームがあれば、それにユーザ入力を追加し、最新ゲーム状態を計算して返す。なければ例外を投げる。|API-A-4|-|
