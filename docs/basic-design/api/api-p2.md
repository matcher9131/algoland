# API一覧（ポンプ）

|ID|リクエスト|引数|返り値|詳細|呼び出すAPI|備考|
|---|---|---|---|---|---|
|API-P2-R|GET|問題ID|ゲーム結果|ユーザの最新ゲームがあれば、そのユーザ入力の最新の履歴を返す。なければ空の履歴を返す。|API-A-4|-|
|API-P2-C|POST|問題ID, ユーザ入力|ゲーム結果|新規ゲームを作成し、その履歴にユーザ入力を追加する。<br>入力を元にゲーム結果(correct, incorrect)を求めて返す。|API-A-4, API-C-C|他の問題と異なり、入力を受け付けるたびに新規ゲームとして記録する|
