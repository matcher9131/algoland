# sc-p-33 - 問題「ダンジョン」Lv3

## 問題概要

プレイヤーキャラを操作し、グリッド迷路のスタートからゴールまでを最小限のコストで移動する

### 迷路の仕様

- 縦15マス横20マス（※検討の余地あり）
- あらかじめ用意された5パターンのうちから、各ユーザに対し（クリアしたかどうかに関わらず）選ばれた回数が最も少ないものが選ばれる
  - 複数ある場合はランダム
- モンスターがいるマスがいくつか存在する
- ユーザはモンスターを含めた迷路の全てが見える
- スタートは左上隅
- スタートから到達不能なマスは無い


## 問題文

王様の依頼を達成しさらに有名になったあなたのもとに、次なるダンジョンの攻略依頼が届きました。

そのダンジョンも迷路状で床が全て毒沼ですが、今度はモンスターも出現します。

名だたる冒険家のあなたにとってモンスター討伐はなんてことはない仕事ですが、流石にノーダメージでというわけにはいきません。

しかし今回のあなたには切り札があります。ダンジョンのフロアすべてを見通せる透視能力です。

この能力を駆使して、HPの消費量が最小になるようにしてゴールに辿り着いてください。


## 制約
- 初期HPは1000
- 1マス移動するごとにHPが1減少する
- モンスターを倒す際にHPが10減少する
- 倒されたモンスターは復活しない
- スタートからゴールまでに消費するHPを最小にできれば正解、そうでなければ不正解
