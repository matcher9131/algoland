# sc-p-32 - 問題「ダンジョン」Lv2

## 問題概要

プレイヤーキャラを操作し、グリッド迷路のスタートから指定された歩数以内で全てのマスを巡回しスタートに戻る

### 迷路の仕様

- 縦15マス横20マス（※検討の余地あり）
- あらかじめ用意された5パターンのうちから、各ユーザに対し（クリアしたかどうかに関わらず）選ばれた回数が最も少ないものが選ばれる
  - 複数ある場合はランダム
- ユーザはキャラのいるマスと隣接4マスのうちどこに行けるかしか見えない
- スタートは左上隅とは限らない
- スタートから到達不能なマスは無い
- フロント側を覗き見るズルを防止するため、迷路の構造はフロント側では持たない（移動するごとにBE側で判定）

### マーカー

攻略の助けとして以下のマーカーを用意する。使用個数・回数に制限はない

- マスに赤・緑・青・黄・紫の旗を立てる
- マスに上下左右矢印を置く

なおBE負荷軽減のため、これらはlocalStorageで管理する


## 問題文

かの悪名高きダンジョンを攻略して一躍有名になったあなたのもとに、なんと王様からの依頼が舞い込みました。曰く「とあるダンジョンの完璧な地図を作ってほしい」とのことです。

そのダンジョンは前回と同様、このダンジョンはモンスターこそ出現しませんが、迷路状で暗く、しかも床が全て毒沼です。

さらなる富と名声を求めるあなたは、もちろんこの依頼を断ることなどしません。HPが尽きるよりも前に、フロアの全てを探索してスタートマスに戻ってください。

※ 攻略の助けとして各種マーカーを用意しています。使用回数に特に制限はありません。


## 制約
- 初期HPは600
- 1マス移動するごとにHPが1減少する
- HPが0になるよりも前に全てのマスを踏破したうえでスタートに戻ればクリア
  - HPが0になると同時に上記条件を満たした場合は失敗とする
